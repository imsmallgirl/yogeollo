## 주요 동작과 결정
- 인원·시간을 우선 제한하고 VERIFIED 사실 및 국내 상품 또는 플레이 근거가 있는 후보만 사용한다. 인원과 검증 조건은 완화하지 않는다.
- 엄격 시간 → 부분 겹침 → 인접 시간 순으로 부족한 결과를 보충한다. 엄격 후보가 5개면 완화하지 않는다. 5개를 채우기 위해 범위를 계속 늘리거나 게임을 생성하지 않는다.
- 겹침 단계도 바로 이웃한 시간 구간 안으로 한정했다. 이는 기존 설계의 구체화이며 구현 전에 이유를 보고했다. 30~60분 선택에 45~90분은 허용하지만 1~600분은 제외한다. 단, 120분 이상 구간 자체에는 정의상 상한이 없다.
- 같은 시간 단계에서 국내 재고·상품 노출·품절·플레이 근거를 구분하고, 추천 인원·분위기·난이도·한국어 사용 편의를 비교한다. 분위기·난이도는 선호 조건이며 불일치를 설명한다.
- 다양성은 앞선 비교가 모두 같은 후보 사이에서만 적용한다. 미확인 장르·메커니즘을 신규 장르로 간주하지 않는다.
- PENDING / STALE / REJECTED 자체 편집을 사용하지 않는다. 실제 샘플의 평균·추천 인원·난이도·태그를 임의로 채우지 않았다.
- 중복 slug 또는 id는 첫 적격 레코드를 유지하며, 잘못된 자료는 필드 경로만 진단하고 원시 오류 값을 반환하지 않는다.
- 결과는 JSON 직렬화 가능하며 근거 없는 적합도·인기·정확도 수치가 없다. 입력·출력 간 가변 배열 참조를 공유하지 않는다.

## 최종 검증
| 검사 | 결과 |
| --- | --- |
| `pnpm lint` | 통과, 오류·경고 0 |
| `pnpm typecheck` | 통과, Prisma 생성·Next 타입 생성·TypeScript strict 검사 |
| `pnpm test` | 6 파일·119 테스트 통과: 기존 21개 + Phase 2 98개 |
| `pnpm build` | 통과, 기존 홈·404·robots·sitemap 정적 생성 |
| `pnpm peers check` | 충돌 없음 |
| `git diff --check` | 통과 |

추천 테스트는 2·4·7·8·10인, 추가 인원 검증, 결과 없음·최대 5개, 시간 경계·120분 이상·완화 제한·완화 순서, 분위기 5종, 난이도·상관없음, 국내 근거·언어, 미검토 편집, 중복·누락, 다양성, 동률·순서 독립성, 입력 불변성·JSON 직렬화·실제 샘플 미확인값 보존을 포함한다.

DB 코드·스키마를 변경하지 않아 PostgreSQL 통합 테스트는 재실행하지 않았다. Phase 1에서 20개 통과한 기록은 이전 보고서에 있다. UI·사용자 흐름을 변경하지 않아 Playwright도 이번 단계에는 재실행하지 않았다. 빌드는 기존 환경의 Turbopack 로컬 포트 제한 때문에 승인된 권한으로 수행했다.

## 미완료와 공개 경계
웹사이트는 계속 준비 화면이다. 조건 폼·URL 쿼리·추천 API/서버 연결·결과 카드는 Phase 3, 상세 페이지·룰렛은 Phase 4다. 반환하는 detailPath는 향후 상세 페이지용이며 아직 UI에 노출하지 않았다.

실제 데이터는 기존 개발용 샘플 1개뿐이다. 공개 승인 완료 자료는 아직 0개이며 출처·판본·이용 범위·자체 편집의 사람 검토와 추가 검증 게임 확보가 남아 있다. 엔진 테스트의 합성 자료를 실제 데이터로 저장하지 않았다. 추천 후보 판정은 공개나 데이터 재이용 허가를 대신하지 않는다.

명시된 검증 상태를 따르며 현재 시각 기반의 자동 신선도 기준이나 새 데이터 수집 정책은 만들지 않았다. 중복 충돌은 임의 병합하지 않으며 실제 repository의 고유성 제약을 계속 유지해야 한다. 주요 장르·메커니즘은 검토된 배열 첫 항목이라는 편집 계약이 있다.

**Phase 2 완료 커밋을 남기고 종료한다. 사용자 승인 전까지 Phase 3를 시작하지 않는다.**
