# 요걸로 제품 요구사항

## 목표와 범위
한국 사용자가 모임의 인원·시간·분위기·난이도를 입력하면 실제 국내 유통 또는 플레이 근거가 있는 보드게임 최대 5개를 추천받는다. 단순 목록 탐색보다 모임의 의사결정을 돕는다. 모든 사용자 UI는 한국어이며 모바일을 우선한다.

현재 Phase 2까지 구현했다. 준비 화면·도구·DB 기반·소량 사실 확인 샘플 1개와 UI 독립 추천 엔진을 제공한다. 공개 승인 완료 데이터는 0개다. 추천 폼·결과 화면·API 연결·상세·룰렛은 아직 구현하지 않는다. 100개 데이터 확보는 장기 목표이며 다음 Phase는 별도 승인이 필요하다.

## 입력과 결과
- 인원: 2·3·4·5·6·7명 이상. 7명 이상 선택 시 정확한 정수 인원을 입력한다. 지원 상한은 데이터 기반으로 안내하며 임의로 7명으로 치환하지 않는다.
- 시간: 15분 이내, 15~30분, 30~60분, 60~120분, 120분 이상.
- 분위기: 웃기고 시끌벅적함, 진지한 전략, 추리와 심리전, 협력, 편안하고 가벼움.
- 난이도: 입문자·초급·중급·상급·상관없음.
- 최대 5개 결과에 한국어 이름, 허가된 이미지 또는 자체 대체 디자인, 가능 인원, 추천 인원, 평균 시간, 난이도, 장르, 추천 이유, 상세 링크를 표시한다. 근거 없는 적합도 백분율은 없다.
- 평균 시간이 원자료에 없으면 시간 범위를 표시한다. 범위 중간값을 실제 평균으로 표시하지 않는다.
- 결과 부족 시 완화 조건을 게임별로 알리고, 0개일 때 조건 변경을 안내한다. 인원 조건은 완화하지 않는다.

## 페이지와 사용자 흐름
`/` 조건 입력 → `/recommend` 공유 가능한 검증된 쿼리 조건과 추천 결과 → `/games/[slug]` 상세. `/about`은 추천 기준·데이터 출처 정책을 설명한다. 현재는 `/` 준비 화면만 제공하며 나머지는 404다.

상세는 소개, 가능·권장 인원, 시간, 난이도, 분위기, 준비, 기본 진행, 승리 조건, 대상, 주의점을 제공한다. 규칙은 자체 요약 또는 허가된 자료만 사용한다.

룰렛은 추천 결과 중 선택한 후보만 대상으로 실행하고 결과를 텍스트로도 제공한다. 빈 선택은 실행 불가, 한 후보는 즉시 선택한다. 선택 변경과 중복 실행을 제어하고 reduced-motion을 존중한다.

## 품질·완료 기준
키보드 조작, 명시적 레이블, 상태 알림, 충분한 대비, 320px 이상 가로 넘침 없는 화면을 지향한다. 비밀정보와 DB 접근은 서버에 한정한다. 데이터 출처·확인일·검증 상태를 보존한다. 실제 인기와 판매를 구분한다.

최종 기능 검증은 2·4·7명 이상, 결과 없음, 시간·분위기·난이도, 중복·누락, 상세·룰렛·모바일을 포함한다. Phase 0의 완료 조건은 설치·lint·타입·기초 단위 테스트·빌드 및 기본 화면 smoke 검증이다.
