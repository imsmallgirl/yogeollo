# 개발용 사실 확인 샘플

현재 15개 게임을 포함합니다. 신규 14개의 출처·수치·판본 범위는 [데이터 확장 보고서](../../docs/DATA_EXPANSION_1_REPORT.md)를 참고하세요. JSON의 `VERIFIED`는 명시된 필드의 공개 출처를 대조했다는 뜻이며, 서비스 공개 승인·라이선스 취득·모든 판본의 동일성 검증을 뜻하지 않습니다.

- 스플렌더: [국내 유통사 공식 채널](https://link.inpock.co.kr/koreaboardgames)에서 상품명·노출을, [퍼블리셔](https://www.asmodee.it/product/splendor/)에서 기본판 2~4인·표기 30분을 확인했습니다.
- 국내 재고·인기·한국어판과 추천 인원·난이도·언어 의존도는 미확인입니다. 평균 시간을 임의 계산하지 않았습니다.
- 자체 소개·추천 태그는 `editorial`에 분리된 `PENDING` 초안입니다. 기본 서버 조회는 이를 공개하지 않습니다.
- 자동 수집·BGG API·외부 이미지·규칙 원문 복제는 사용하지 않았습니다. `FACTS_ONLY`는 사실 기록 범위이며 복제 허가를 뜻하지 않습니다. 공개 전 사람의 이용 범위·출처 검토가 필요합니다.

새 게임을 추가할 때 필드별 출처·관측일·이용 근거를 기록하고 Zod 검증을 통과해야 합니다. `data/catalog.ts`에 명시한 동일 목록을 DB seed와 개발 미리보기가 함께 읽으며 임의의 폴더 전체를 수집하지 않습니다. 새 파일을 넣을 때는 이 목록에도 추가하세요. 검토 기반 가져오기 절차는 [Phase 5 문서](../../docs/DATA_IMPORT.md)를 따릅니다.

신규 14개는 자체 편집을 추측하지 않아 editorial=null입니다. 개발 에이전트의 사실 확인을 사람의 검토로 표시하지 않습니다. 운영 공개 승인 목록은 별도이며 현재 비어 있습니다.
